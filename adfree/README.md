# 광고 없이

웹 광고를 막고, 광고가 빠진 빈 자리를 정리하고, 유튜브 영상 광고를 건너뛴다.

`quiet-web` 과 일부러 분리했다. 광고 차단 기능이 붙으면 스토어 심사에서 광고 차단 카테고리로
분류되어 심사가 훨씬 까다로워진다. 섞었다면 둘 다 못 올릴 수 있다.

## 세 가지 방식을 쓴다

| 방식 | 대상 | 파일 |
| --- | --- | --- |
| 네트워크 차단 | 제3자 광고·추적 도메인 | `rules/network.json` |
| 화면 정리 | 광고 자리 표시가 붙은 요소 | `src/cosmetic.js` |
| 재생 건너뛰기 | 유튜브 영상 광고 | `src/youtube.js`, `src/youtube.css` |

## 유튜브에서는 일부러 네트워크를 막지 않는다

이 확장에서 제일 중요한 설계 결정이다.

유튜브의 광고차단 감지는 **광고 리소스가 로드에 실패했는지**를 보는 방식이 많다.
그래서 광고 요청을 막으면 오히려 감지에 걸려 "광고 차단 프로그램은 이용약관 위반입니다" 창이 뜨고
재생이 막힌다.

그래서 `rules/network.json` 의 3번 규칙이 **유튜브에서 발생한 요청 전부를 명시적으로 통과**시킨다.
광고는 정상적으로 내려받게 두고, `src/youtube.js` 가 플레이어 단에서 처리한다.

1. `건너뛰기` 버튼이 뜨면 누른다 — 유튜브가 정상 동작으로 취급하는 경로다
2. 못 건너뛰는 광고면 소리를 끄고 재생 위치를 끝으로 민다

화면의 광고 자리(피드 광고, 마스트헤드 등)는 CSS 로 **숨기기만** 한다. 요청을 막지 않으므로 감지되지 않는다.

### 감지되면 숨기지 않고 알린다

그래도 유튜브가 알아채면 확장 아이콘에 빨간 `!` 가 뜨고, 팝업에 사실대로 표시된다.
감지를 회피하려고 더 싸우지 않는다. 그 싸움은 끝이 없고, 질 때마다 사용자가 재생을 못 하게 된다.

## 국내 포털 광고를 위한 별도 규칙

1번 규칙은 `thirdParty` 로 좁혀 오탐을 줄인다. 그런데 네이버·다음의 광고 호스트는
본체와 같은 도메인이라(`veta.naver.com` ↔ `naver.com`) 이 조건에 걸리지 않는다.
그래서 2번 규칙이 그 호스트들만 콕 집어 따로 막는다.

## 숫자를 부풀리지 않는다

크롬 MV3 에서는 **네트워크에서 몇 개를 막았는지 배포판에서 알 수 없다.**
그 정보를 주는 `declarativeNetRequestFeedback` 권한은 개발자 모드 전용이기 때문이다.

그래서 팝업에는 **실제로 확인한 것만** 센다 — 화면에서 치운 광고 자리, 건너뛴 영상 광고, 닫은 겹침 배너.
다른 확장들이 보여주는 "오늘 1,847개 차단!" 같은 숫자는 여기서는 만들 수 없고, 지어내지도 않는다.

## 아는 한계

- **규칙 목록은 계속 낡는다.** 광고 차단은 코드가 아니라 목록이 본체다.
  지금 목록은 잘 알려진 47개 도메인으로 시작하는 보수적인 것이다. 전면전을 하지 않는 대신 잘 안 깨진다.
  본격적으로 막고 싶다면 uBlock Origin Lite 를 같이 쓰는 게 낫다.
- **유튜브 부분은 주기적으로 깨진다.** 유튜브가 플레이어 구조를 바꾸면 `src/youtube.js` 부터 깨진다.
  고칠 곳이 그 파일 하나로 모이도록 짜뒀다.
- 화면 정리는 **광고 자리라고 이름표가 붙은 것만** 지운다. 추측으로 지우지 않는다.
  멀쩡한 내용이 사라지는 게 광고가 남는 것보다 훨씬 나쁘기 때문이다.

## 스토어 등록에 대해

광고 차단 확장은 스토어에서 허용된다. 다만 `<all_urls>` 권한과 광고 차단 성격 때문에
심사가 다른 확장보다 까다롭다. `yt-shelf` 를 먼저 올려 절차를 겪어본 뒤에 시도하는 걸 권한다.

## 확인이 필요한 것

브라우저에서 아직 돌려보지 않았다. 규칙 파일은 스키마 검증만 통과한 상태다.

1. `rules/network.json` 이 크롬에 정상적으로 로드되는지 (규칙 하나라도 틀리면 규칙셋 전체가 실패한다)
2. 유튜브에서 광고가 실제로 건너뛰어지는지, 그리고 감지에 걸리는지
3. 국내 사이트(네이버·다음·쿠팡)에서 멀쩡한 기능이 깨지지 않는지 — 이게 제일 중요하다
4. 광고를 지운 자리가 빈 상자로 남지 않는지
