# 영상 선반

유튜브 영상을 **내 태그로** 분류해 모아두고, 몇 번 봤는지 기록하고, 태그 단위로 공유하는 확장.

유튜브 화면 오른쪽에 **포스트잇 색인 탭처럼 탭이 세로로 붙는다.**
첫 탭은 언제나 `전체` 이고, 그 아래로 태그마다 탭이 하나씩 자기 색을 달고 붙는다.
탭을 누르면 서랍이 밀려나오면서 그 태그의 영상만 보인다. 서랍이 열리면 탭도 같이 밀려서 옆에 계속 붙어 있는다.

## 화면에서 신경 쓴 것

- **한글이 어절 중간에서 끊기지 않는다.** `word-break: keep-all` 을 적용했다.
  이게 없으면 크롬이 "게임 개발 브이로그" 를 "게임 개발 브이로 / 그" 처럼 아무 데서나 자른다.
- **탭 글자는 세로쓰기를 쓰지 않는다.** `writing-mode` 로 세로쓰기를 하면 한글이 한 글자씩 쌓여 읽기 나빠진다.
  글자를 가로로 정상 배치한 뒤 박스째 90도 돌리고, 탭 높이는 글자 폭을 실제로 재서 맞춘다.

  크롬에서 실제로 측정한 값:

  | 탭 라벨 | 회전 전 | 회전 후 | 탭 높이 |
  | --- | --- | --- | --- |
  | `게임 개발 12` | 69 × 16px | 16 × 68px | 95px |
  | `전체 24` | 41 × 16px | 16 × 41px | 67px |
  | `나중에 볼 것 7` | 78 × 16px | 16 × 77px | 104px |

  회전 전 높이가 전부 16px(한 줄)이다. 글자가 쌓였다면 여기가 60~80px 로 나온다.
- **유튜브 어두운 테마를 따라간다.** `<html dark>` 속성을 지켜보다가 같이 바뀐다.
  검은 화면에 흰 서랍이 튀어나오지 않는다.
- **아이콘은 이모지가 아니라 SVG 다.** 이모지는 OS 마다 모양이 달라 통일감이 없다.
- 전체 화면으로 보면 서랍이 스스로 숨는다.

## 되는 것

| 기능 | 설명 |
| --- | --- |
| 색인 탭 | 태그마다 탭이 하나. 누르면 그 태그만 보인다. 첫 탭은 언제나 `전체` |
| 탭 색 | 탭이 열린 상태에서 머리의 색 동그라미를 누르면 8색 중에 고른다. 안 고르면 태그 이름에서 항상 같은 색이 나온다 |
| 저장 | 보고 있는 영상을 태그와 함께 선반에 넣는다. 제목·채널·길이는 자동으로 들어간다 |
| 채널 자동 태그 | "이 채널 영상에는 항상 `게임` 태그" 규칙. 다음부터 저장하면 알아서 붙는다 |
| 시청 횟수 | 30초 이상 보면 1회로 센다. **하루에 한 번만** 세서 숫자가 부풀지 않는다 |
| 분류해 보기 | 최근순 / 채널별 / 태그별 / 많이 본 순 / **아직 안 본 것** |
| 고정 | 서랍 고정(페이지를 옮겨도 열린 채 유지)과 영상 고정(목록 맨 위) 두 가지 |
| 내 평가 | 👍 / 👎 를 내 기록으로 남긴다. 유튜브에는 아무것도 보내지 않는다 |
| 공유 | 아래 참조 |
| 백업 | JSON 내보내기 / 가져오기 |

## 공유 방식 두 가지

### 1. 유튜브 링크 — 상대는 확장이 없어도 된다

`https://www.youtube.com/watch_videos?video_ids=아이디1,아이디2,...`

유튜브가 이 주소를 받으면 **임시 재생목록을 만들어서** 재생 화면으로 보내준다.
카톡으로 링크만 보내면 상대는 아무것도 설치하지 않고 재생목록으로 본다.

- 확인함: 2026년 8월 기준 동작. 세 개 ID 를 넣으면 `watch?v=...&list=TLGG...` 로 리다이렉트된다
- 한계: 약 50개까지. 태그나 내 평가는 넘어가지 않는다 (유튜브가 모르는 정보라서)

### 2. 공유 코드 — 태그까지 그대로 넘긴다

목록을 JSON 으로 만들어 브라우저 내장 압축(`CompressionStream('deflate-raw')`)으로 줄이고
base64 로 바꾼 문자열. 외부 라이브러리를 쓰지 않는다.

받는 쪽은 확장 팝업에 붙여넣으면 태그까지 그대로 들어온다. 이미 있는 영상은 태그만 합쳐진다.

- 확인함: 한글 제목·태그가 붙은 영상 30개 → **482자**, 왕복 후 내용 완전 일치.
  카톡에 붙여넣을 만한 길이다.

## 안 만든 것

**좋아요 / 싫어요 자동 누르기는 넣지 않았다.**
다른 사람에게 가는 공개 신호를 조작하는 일이고, 유튜브가 자동화된 참여를 계정 정지 사유로 다룬다.
확장 하나 때문에 계정을 잃는 건 손해가 너무 크다.

대신 같은 편의를 **내 평가**(선반 안의 개인 기록)와 **채널 자동 태그**로 나눠 넣었다.

## 구조

```
yt-shelf/
├─ manifest.json
├─ icons/
└─ src/
   ├─ page.js      # MAIN 월드. 플레이어에서 제목·채널명만 읽는다
   ├─ store.js     # 저장소 + 공유 코드 인코딩/디코딩
   ├─ drawer.js    # 서랍 UI 전부
   ├─ drawer.css   # Shadow DOM 안에서만 적용되는 스타일
   └─ popup.*      # 공유 코드 받기, 백업
```

### 왜 이렇게 만들었나

- **유튜브 DOM 안쪽에 아무것도 끼워넣지 않는다.** 서랍은 화면 위에 독립적으로 떠 있을 뿐이라
  유튜브가 화면 구조를 바꿔도 깨지지 않는다. 좋아요 버튼 옆에 뭔가를 붙이는 방식이었다면 몇 달 못 간다.
- **Shadow DOM 으로 스타일을 격리했다.** 유튜브 CSS 가 서랍으로 넘어오지도, 서랍 CSS 가 유튜브로 새지도 않는다.
- **제목·채널명을 CSS 선택자로 긁지 않는다.** 플레이어 객체에 직접 물어본다. 이 경로는 `yt-grab` 을 만들면서 실제로 확인했다.
- **유튜브가 페이지를 새로 읽지 않으므로** 주소가 바뀌는지 직접 지켜본다(0.7초 간격).

## 확인이 필요한 것

브라우저에서 아직 돌려보지 않았다.

1. Shadow DOM 서랍이 유튜브 화면을 가리지 않고 잘 뜨는지 (특히 극장 모드·전체 화면)
2. 클립보드 복사가 되는지 (막히면 대체 경로로 넘어가게 해뒀다)
3. 시청 횟수가 의도대로 하루 한 번만 올라가는지
4. 공유 코드가 왕복하는지 (압축 → base64 → 압축 해제)

## 나중에 할 만한 것

- 서랍 폭을 끌어서 조절
- 태그 이름 바꾸기 / 태그 합치기
- 영상별 메모
