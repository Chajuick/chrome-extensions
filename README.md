# chrome-extensions

직접 쓰려고, 그리고 주변 사람들한테 깔아주려고 만드는 크롬 확장프로그램 모음.

폴더 하나가 확장 하나다. 빌드 도구 없이 순수 HTML/CSS/JS + Manifest V3 로만 만든다.
그래야 폴더를 그대로 크롬에 올릴 수 있고, 친구한테 줄 때도 압축해서 보내면 끝난다.

## 만든 것

| 폴더 | 이름 | 한 줄 설명 | 상태 |
| --- | --- | --- | --- |
| [`quiet-web/`](./quiet-web) | 조용한 웹 | 사이트에 뜨는 팝업·쿠키창·앱 설치 배너를 알아서 닫아준다 | 개발 중 |
| [`yt-shelf/`](./yt-shelf) | 영상 선반 | 유튜브 영상을 내 태그로 분류하고, 본 횟수를 세고, 태그 단위로 공유한다 | 개발 중 |
| [`adfree/`](./adfree) | 광고 없이 | 웹 광고를 막고 빈 자리를 정리한다. 유튜브 영상 광고는 건너뛴다 | 개발 중 |
| [`tab-audio/`](./tab-audio) | 탭 소리 녹음 | 탭에서 재생되는 소리를 그대로 WAV 로 녹음한다 | 개발 중 |
| [`yt-grab/`](./yt-grab) | 내 영상 받기 | 유튜브 영상의 오디오·영상 내려받기 | ❌ 중단 |

> `yt-grab` 은 **동작하지 않는다.** 유튜브가 SABR 방식으로 바뀌면서 포맷에 파일 주소가 사라졌다.
> 자세한 확인 결과는 [yt-grab/README.md](./yt-grab/README.md) 에 기록해뒀다.
> 본인 영상은 YouTube Studio 의 공식 다운로드 기능을 쓰면 된다.

## 설치 방법

1. 이 저장소를 내려받는다 (초록색 `Code` 버튼 → `Download ZIP` → 압축 풀기)
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드**를 켠다
4. **압축해제된 확장 프로그램을 로드** 클릭
5. 설치할 확장의 폴더(예: `quiet-web`)를 고른다

## 새 확장 추가할 때

```
새폴더/
├─ manifest.json
├─ src/
└─ icons/
```

만들고 위 표에 한 줄 추가. 그게 전부다.

## 원칙

- **설명서가 필요 없어야 한다.** 깔면 바로 동작하고, 설정 화면이 없거나 버튼 두세 개면 된다.
- **서버를 두지 않는다.** 데이터는 `chrome.storage.local` 에만 둔다. 회원가입도 없다.
- **API 비용이 드는 기능은 넣지 않는다.** 지인에게 나눠주는 순간 내 지갑이 털린다.
- **개인정보는 커밋하지 않는다.** 주소·계좌번호·전화번호를 테스트한다고 코드에 박아두지 말 것.

## 언제 저장소를 분리하나

확장 하나가 크롬 웹스토어에 올라가거나, 다른 사람이 기여하기 시작하거나,
사용자가 생겨서 이슈를 받게 되면 그 폴더만 별도 저장소로 옮긴다. 그 전까진 여기 둔다.
