# 조용한 웹

사이트에 뜨는 팝업, 쿠키 안내창, "앱으로 보기" 배너를 알아서 닫아주는 크롬 확장.

설정할 게 없다. 깔면 그때부터 동작한다.

## 어떻게 동작하나

페이지가 열릴 때와 그 뒤 몇 초 동안 화면을 덮는 요소를 찾는다. 찾으면 둘 중 하나를 한다.

1. **안전한 닫기 버튼이 있으면 그걸 누른다.**
   `오늘 하루 보지 않기` → `닫기` → `나중에` 순으로 우선순위를 둔다.
   `오늘 하루 보지 않기` 를 제일 먼저 찾는 이유는, 그걸 눌러두면 사이트가 기억해서 다음에 안 뜨기 때문이다.

2. **안전한 버튼이 없으면 누르지 않고 화면에서 숨기기만 한다.**
   쿠키 배너처럼 `모두 동의` 밖에 없는 경우가 여기 해당한다.
   숨기기는 서버에 아무것도 보내지 않으므로 동의한 것으로 처리되지 않는다.

모달이 뜨면서 사이트가 스크롤을 잠가둔 경우, 모달을 치운 뒤 스크롤도 같이 풀어준다.

## 안전장치

잘못 눌러서 손해가 나면 안 되므로 규칙을 네 개 두었다. `src/patterns.js` 와 `src/content.js` 상단에 정리되어 있다.

| 규칙 | 내용 |
| --- | --- |
| 위험 버튼 금지 | `동의` `허용` `결제` `구매` `설치` `로그인` `삭제` 계열은 절대 누르지 않는다 |
| 민감 페이지 제외 | 결제·로그인·인증 경로, 은행/카드/증권 도메인, `.go.kr` 에서는 아예 동작하지 않는다 |
| 사용자 조작 존중 | 사용자가 클릭한 뒤 1.2초 안에 뜬 창은 건드리지 않는다 (직접 연 창이므로) |
| 되돌리기 | 숨긴 것은 전부 기록해두고 팝업의 `되돌리기` 로 복구할 수 있다 |

본문을 팝업으로 오인하지 않기 위한 조건도 있다. 글자 수가 1200자를 넘거나, `<main>`/`<article>` 을 품고 있거나,
비밀번호 입력칸이 있거나, 링크가 12개를 넘으면 손대지 않는다.

## 자동으로 못 잡은 팝업이 있다면

확장 아이콘 클릭 → **직접 지우기** → 없앨 팝업을 클릭.

그 사이트에 한해 선택자를 기억해두고, 다음 방문부터 자동으로 없앤다. `ESC` 로 취소.

## 파일 구조

```
quiet-web/
├─ manifest.json
├─ icons/                # 아이콘 (scripts 없이 PowerShell 로 생성한 단순 도형)
└─ src/
   ├─ patterns.js        # 판별 규칙 전부. 오작동은 대부분 여기만 고치면 된다
   ├─ content.js         # 본체 — 탐지, 클릭/숨기기, 스크롤 복구
   ├─ picker.js          # '직접 지우기' 모드
   ├─ content.css        # 페이지 위에 얹는 UI
   ├─ background.js      # 기본 설정 + 아이콘 배지
   └─ popup.html/css/js  # 확장 아이콘을 눌렀을 때의 화면
```

## 아직 안 되는 것

- **iframe 안의 팝업은 못 잡는다.** 최상위 문서에서만 동작한다 (`all_frames: false`).
  임베드된 영상·지도를 잘못 건드릴 위험을 피하려고 일부러 이렇게 뒀다.
- 페이지 이동 없이 화면이 바뀌는 사이트(SPA)에서는 첫 로드 이후 감지가 약할 수 있다.
- 아이콘이 임시 도형이다.

## 테스트할 때 볼 것

주로 오작동(멀쩡한 걸 지움)을 확인해야 한다. 아래를 돌아보면서 확인.

- 뉴스 사이트 (기사 본문이 안 지워지는지)
- 쇼핑몰 (상품 상세, 장바구니 레이어가 살아있는지)
- 사이트 자체 메뉴·헤더가 멀쩡한지
- 로그인 화면에서 아무 일도 안 일어나는지
